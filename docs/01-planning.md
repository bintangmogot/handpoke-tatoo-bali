# Phase 1: Planning & Documentation

## Problem Statement
Dotlinetattu is an established traditional handpoke tattoo studio in Bali with 5-star Google Reviews and authentic storytelling. However, the current website built on Hostinger AI Builder lacks an integrated conversion flow, forcing users to leave the site to book via an external Linkbio. Furthermore, scheduling overlaps and the lack of a proper consultation/payment system hinder professional expansion and booking efficiency.

## Development Phases
- **Phase 1:** Planning & Documentation (Current)
- **Phase 2:** UI/UX Design (Stitch / Tailwind Mockups)
- **Phase 3:** Project Scaffolding
- **Phase 4:** Core Layout & Static Pages Implementation
- **Phase 5:** Supabase & Dual Booking Engine Logic
- **Phase 6:** Payment Integration (Xendit) & Emails (Resend)
- **Phase 7:** SEO, Testing, and Deployment

## Tech Stack
- **Framework:** Next.js 15 (App Router, TypeScript)
- **Styling:** Tailwind CSS 4
- **Database:** Supabase (PostgreSQL)
- **Payment Gateway:** Xendit (QRIS, CC, E-Wallet)
- **Email API:** Resend
- **Hosting:** Vercel (Free Tier)
- **Domain:** dotlinetattu.com
