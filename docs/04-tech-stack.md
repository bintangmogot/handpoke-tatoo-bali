# Tech Stack & Rationale

- **Framework:** Next.js 15 (App Router, TypeScript) - For SEO, Server Components, and seamless API routes for Xendit/Emails.
- **Styling:** Tailwind CSS 4 - Standard utility-first framework for Dark Industrial theme.
- **Database:** Supabase - Real-time availability checking and admin booking management.
- **Payment:** Xendit - Process IDR/USD, 50% deposits (QRIS, E-Wallet, CC).
- **Email:** Resend API - High deliverability for automated PDF invoices and booking confirmations.
- **Hosting:** Vercel (Free Tier) - Automatic deployments and edge network.
