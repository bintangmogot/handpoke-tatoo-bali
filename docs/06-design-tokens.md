# Design Tokens

## Colors
- `--bg-primary`: `#0a0a0a` (Deep charcoal/black)
- `--bg-secondary`: `#141414` (Card backgrounds)
- `--accent`: `#ea580c` (Orange-600 - Main CTA & Stars)
- `--text-primary`: `#fafafa` (White-ish text)
- `--text-secondary`: `#a3a3a3` (Muted text)
- `--surface`: `#1c1c1c` (Inputs, dropdowns)

## Typography
- `--font-heading`: `"Space Grotesk", sans-serif` (Bold, industrial feel)
- `--font-body`: `"Inter", sans-serif` (Clean readability)

## Spacing & Radius
- Base scale: `4px` grid (Tailwind defaults)
- Rounded: `rounded-lg` for cards, `rounded-md` for buttons

## Micro-animations
- `transition-all duration-300 ease-out` on all interactive elements
- Hover states: `scale(1.02)` and orange glow `shadow-orange-500/20`
